## Bounded implementation

- Export the complete active Creator/Workspace data families from the authorized Workspace with pagination and no silent truncation.
- `conversation_messages` is no longer Meta-only; all stored channel messages for the Workspace are included.
- Active CRM tables are read with `select=*` so existing safe fields are not lost through stale narrow projections. Every returned row must still bind to the authorized Workspace (or exact Workspace id for the Workspace row).
- The Workspace row is included so contract/billing/master-data fields stored in FanMind are represented, while provider credential fields are removed.
- Contact rows are present both in the existing human-friendly contact section and in the complete raw Workspace dataset so ids/current fields are not lost.
- Account `user_metadata` and the current Workspace role are added as an explicit profile/preference section.
- Social/Workspace rows are sanitized before PDF generation. Stripe provider identifiers, passwords, secrets, ciphertext and access/refresh/API-token fields are excluded. Data from other Workspaces is rejected.
- Missing/denied/malformed/network-failed active data is never converted into an empty result. A later-page failure aborts the complete disclosure.
- Error UI remains localized DE/EN with retry/back links, no raw diagnostics or personal data, private no-store, nosniff, no-referrer and restrictive CSP.
- No database migration, RLS/grant change, provider activation, payment, account deletion or credential mutation is part of this fix.
